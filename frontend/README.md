# Invitación de boda Jeick y Fernanda

Invitación digital móvil creada con React y Vite.

## Desarrollo local

```bash
npm install
npm run dev
```

## Publicar en Vercel

1. Sube este proyecto a un repositorio de GitHub.
2. En Vercel, selecciona **Add New Project** e importa el repositorio.
3. Vercel detectará Vite automáticamente.
4. Usa estos valores si los solicita:
   - Build command: `npm run build`
   - Output directory: `dist`
5. Pulsa **Deploy**.

La canción está dentro de `public/audio` y se publicará junto con la invitación.
